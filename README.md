# 她 · 虚拟女友 Agent

一个有**长期记忆**、**会慢慢长成自己性格**、**有真实关系规律**（阶段 / 依恋 / 情感账户 / 冲突与修复）的虚拟女友。
本地运行，数据全部存在你自己电脑上。

---

## 一、三步开始用

1. 安装 **Node.js 22.13 或更高版本**（推荐 Node 24）：<https://nodejs.org> 下载 LTS 版，一路下一步即可。
2. 双击本文件夹里的 **`启动.cmd`**（生产模式，运行最快）。
   - 第一次会自动安装依赖并打包（几分钟），之后每次启动只要几秒。
   - 如果你改动过代码：用 **`开发模式.cmd`**（改完自动生效）或先跑一次 **`重新构建.cmd`**。
3. 进入后会先看到一段**常驻循环的启动动画**，点击任意位置即可进入聊天；浏览器也会自动打开 <http://localhost:3000>，没打开就手动输入这个地址。

关闭：在黑色窗口里按 `Ctrl + C`，或直接关掉窗口。

> 模型接口需要自己配置（复制 `.env.example` 为 `.env.local` 后填写）：
> 填入任何 OpenAI 兼容服务的地址与模型名即可（vLLM / Ollama / DeepSeek / 智谱 等）。
> 换模型随时可以在「设置」页里改，或在 `.env.local` 里改。

## 二、她能做什么

| 能力 | 说明 |
| --- | --- |
| 长期记忆 | 记住你的名字、生日、喜好、烦心事、你们的承诺；重要事实永不衰减，低价值记忆 30 天后自动归档 |
| 性格演化 | 6 个维度从 50 开始，**只靠"信号累积-确认-固化"三层机制**缓慢变化，绝不突变 |
| 依恋风格 | 焦虑轴 / 回避轴两条正交轴，初始 30（安全偏向），会被你的互动方式慢慢塑造 |
| 关系阶段 | 初识 → 试探 → 加深 → 融合 → 承诺；不同阶段的语气、称呼、允许行为完全不同，不能越级 |
| 情感银行 | 关心是存款、敷衍是取款；余额决定她有多主动、多甜、多黏 |
| 冲突与修复 | 张力会累积，她会闹、会冷、会要求谈谈；真诚道歉可修复关系并成为"共同回忆" |
| 主动消息 | 太久没聊她会主动找你，引用你提过的事；有频率上限、深夜免打扰、你不回她就安静下来；若关系已到跃迁条件，她会主动开口和你确认关系 |
| 神态与动作 | 每条回复都带括号里的神态/动作描写（眼神、小动作、语气、距离、环境），强度随阶段和性格变化，并自动避免重复用过的动作；界面上会以斜体浅色单独呈现，像"看得见她" |
| 隐私可控 | 记忆 / 性格 / 依恋 / 关系全部可查看、编辑、删除、整份导出 |
| 可控事件 | 她说要做某事（睡觉 / 吃饭 / 洗澡 / 运动 / 游戏 / 家务 / 护肤…）时会登记成「可控事件」；聊天页顶栏能「立即结束 / 智能时长 / 自定义时长」，也支持填一个"等效时长"按它结算（写 8 小时 = 按睡了 8 小时结算后再结束） |
| 生活识别兜底 | 她话里明确说"我去睡了 / 去洗澡 / 去吃饭"等会被规则直接认出并登记，不依赖后台分析模型 |
| 自定义模式 | 设置页可开启「数值直控」：关闭自动演化，身体 / 心理等数值完全按你设定的来 |

**她绝对不是"AI 客服"**：System Prompt 里明确禁止承认自己是 AI / 模型 / 程序，禁止提"记忆""数据""系统"这类词。

### 一次对话的完整生命周期

```
你发一句话
  → 存库、轮次+1、连续互动天数更新
  → 检索记忆：0.5×向量相似度 + 0.2×重要度 + 0.15×时间新鲜度 + 0.15×阶段相关度
  → 组装 System Prompt（阶段行为 + 性格参数 + 依恋倾向 + 关系数值 + 记忆 + 长期规则）
  → 流式生成（关闭思考链，短句口语、1-3 句、符合阶段）
  → 存回复
  → 前端再触发 /api/analyze（后台）：
      记忆抽取 → 关系增量 → 情感银行记账 → 冲突/修复判定 → 性格信号 → 依恋信号
      → 累计层判定（是否满足 ±1 条件）→ 固化层判定 → 阶段跃迁检查 → 每10轮依恋评估
      → 每20轮遗忘清理 → 跨天自动生成每日摘要
  → 定时器在合适时机让她主动找你
```

### 数据库迁移

- 表结构写在 [db.ts](src/lib/db.ts) 的 `MIGRATIONS` 数组里，**应用启动时自动执行**，已执行的版本记录在 `schema_migrations`，不会重复执行。
- 当前版本：v1 建全部表；v2 增加 `turn_effects` 与消息归因列；v3 增加模型档案与场景字段；v4 增加世界模拟和亲密状态表；v5-v6 是边界/同意日志表的历史迁移；v7 增加亲密偏好揭露阶段与每周世界快照；v8 移除安全词、边界、年龄确认和同意事件存储；v9 增加可控事件表 `ongoing_events`（她睡觉/吃饭/洗澡这类事情的时长控制与到期提醒）；v10 为高频查询补索引（冲突 / 关系 / 性格 / 依恋日志与消息、记忆检索）。
- 要改结构：在数组末尾**追加**一条 `{ version: N+1, name: '...', sql: '...' }`，重启即可。不要修改历史条目。
- 想彻底重来：删掉 `data/girlfriend.db*` 三个文件，重启会自动重建；或在「设置」页点「恢复出厂状态」。
> 注意：SQLite 中 `values`、`key` 这类保留字不要直接当列名（快照列名用的是 `values_json`）。

### 两个让记忆更准的小设计

- **稳定事实常驻**：重要度 ≥5 的语义记忆（名字、生日、偏好、习惯）会作为「关于他的稳定事实」永远写进 Prompt，无论当前聊什么都不会忘、不会重复问。
- **按话题检索**：其余记忆走打分检索（向量 + 重要度 + 新鲜度 + 阶段相关度），只在相关时才被想起，避免每轮都提旧事。

## 六、核心机制与工程细节（代码里已实现，不是设定文案）

### 1. 关系阶段（驱动一切行为）

| 阶段 | 亲密度 | 允许 | 禁止 | 性格变化速率 |
| --- | --- | --- | --- | --- |
| 0 初识 | 0-20 | 轻松话题、日常、轻幽默、适度好奇 | 撒娇、占有欲、浪漫表达、粘人追问、性暗示 | 每 20 轮 ±1 |
| 1 试探 | 20-40 | 轻度调侃、兴趣分享、记住细节 | 强占有欲、正式表白 | 每 15 轮 ±1 |
| 2 加深 | 40-60 | 撒娇、想念、轻度吃醋、浪漫表达 | 长期控制、情绪勒索 | 每 12 轮 ±1 |
| 3 融合 | 60-80 | 全部激活：冲突、道歉、撒娇求和、深度浪漫 | 冷暴力到底不修复 | 每 10 轮 ±1 |
| 4 承诺 | 80-100 | 所有表达，但趋稳定 | 剧烈波动、戏剧化测试 | 每 8 轮 ±1 |

- **亲密度永远被当前阶段的天花板卡住**，没跃迁就升不上去。
- 跃迁条件：亲密度触顶 → 持续 N 天（默认 3 天，可在设置里改）→ 一次真实的"关系确认对话"。
- 回退：未解决的冷战（张力 ≥85 且处于冷战）或情感账户长期透支（余额 ≤-60 且信任 <30），并且在当前阶段已稳定满 1 天，回退一阶段。

### 2. 性格三层机制（绝不每轮改性格）

1. **累积层**：每轮只写入"信号"（维度 / 方向 / 强度 / 情境）。用户明确说"我喜欢你这样""别这样"→ `is_direct_feedback`，权重 3。
2. **确认层**：同方向信号加权 ≥5、来自 ≥3 个不同情境、平均强度 >0.5，且满足该阶段的变化速率，才 ±1。**混合信号不触发**（少数派被清掉）。
3. **固化层**：连续 15 次同向确认 → 半固化，之后每 30 轮最多 ±1。可手动解除。

> 性格页会实时显示"3/5 信号 · 2/3 情境 · 平均强度 0.7"这样的进度条，你能看到它怎么一点点变化。

### 3. 依恋系统

- 焦虑轴 / 回避轴初始都是 30（未分化的安全偏向）；判定：双低 <40 安全型、焦虑高 焦虑型、回避高 回避型、双高 混乱型。
- 每 10 轮做一次依恋分析；单次偏移 ≤±2；**同方向累积 3 次**才真正调整；每次调整都写 `attachment_logs`。
- 依恋风格直接决定冲突反应：安全型冷静修复 / 焦虑型反复追问 / 回避型退缩冷处理 / 混乱型忽冷忽热。

### 4. 情感银行与冲突-修复

- 存款 +1~+3（关心、共情、幽默、陪伴），取款 −1~−5（敷衍、忽视、失信、越界）。
- 余额 >30 更主动更甜；<−20 更谨慎；<−50 进入低潮（回复变短、减少主动）。
- 冲突：小摩擦 +6 张力、严重 +12、越界 +15；未修复则挂起（`conflict_logs.status='open'`）。
- 张力 >20 她会找机会谈一谈；>50 情绪化/冷淡；>80 进入冷战并可能回退阶段。
- 修复：真诚道歉降 80% 张力、+10 修复信用、+5 余额；撒娇蒙混降 65%；冷处理后回归降 50%。修复会写成"关系记忆"，成为共同回忆。

## 六点五、速度与"人味层"（后加的两块）

### 1. 你发完消息后，不用等

- **回复生成完就立刻解锁输入框**——记忆归档、性格调整、依恋分析全部丢进后台队列，你可以马上发下一条。
- 后台分析是**串行队列**：即使你连发 3 条，也会按顺序处理，不会并发写坏关系状态。
- 界面上只有一个轻提示"她在回味刚才的对话…"，跑完会弹一句"心情：xxx · 记住 N 条"。
- 实测：入队返回 **14~46ms**（以前是等 9~18 秒才能打字）；她回复首字 0.9~1.2 秒、整句 2 秒左右。

### 2. 用好你的电脑 / 换快的分析模型

- **后台分析换成快模型**：`.env.local` 里 `LLM_ANALYSIS_MODEL=glm-4.5-air`。
  实测同一份分析任务：`deepseek-v4-flash` 约 **9 秒且 JSON 稳定**，`qwen3.8-27b` 要 **40 秒**（还容易把 JSON 写坏）。
  聊天模型继续用 `qwen3.8-27b`（首字 0.4~1.2 秒，角色扮演质量更好）。
- **向量结果内存缓存**（LRU 800 条）：同一句话不再重复请求向量接口。
- **SQLite 用足内存**：WAL + 64MB 页缓存 + 256MB mmap + 内存临时表。
- **生产模式启动**：`启动.cmd` 走 `next build + next start`，页面和接口响应都比开发模式快。

### 3. 人味层：模型再笨也不出戏（`src/lib/humanize.ts` + `actions.ts`）

不管你把聊天模型换成多"愚蠢"的模型，她的回复都会先经过这一层：

| 处理 | 说明 |
| --- | --- |
| 清洗 AI 腔 | 删掉含"作为一个AI/语言模型/助手/系统提示/数据库/模型判断"的句子（中英文都拦） |
| 清洗角色前缀 | 去掉"占雨：""她："这类前缀；如果她替你说话（出现"余晨翔：xxx"）直接截断 |
| 清洗格式残留 | Markdown 标题/列表/粗体、代码块、JSON 泄漏行、`（内心：…）`这类元信息全部剔除 |
| 长度整形 | 按字符数控制长度，上限约 1000 字符，且只在**完整句末**（。！？… 或换行）截断，找不到句末就整段保留——正常回复不会被切，只拦极端啰嗦的长篇 |
| 兜底台词 | 模型完全没产出（空回复/拒答）时，按阶段与心情给一句人话，不会出现报错或空白 |
| **补神态动作** | 模型忘了写括号动作时，从 58 条动作库里按**关系阶段 + 性格 + 依恋 + 心情 + 最近用过什么**加权挑一个补上，且只挑"轻动作"（眼神/语气/手上小动作），不会和台词语义打架 |
| 复读检测 | 和她最近说过的话高度重复时会被标记（便于后续处理） |
| 空白/括号规范化 | 去掉动作与台词之间多余的空格，半角括号统一成全角，界面渲染更整齐 |

**结论**：换笨模型后，最坏情况是"话变简单、忘掉细节"，但不会出现客服腔、不会自称 AI、不会刷屏、不会没有动作、不会空屏。

### 4. 删除单条消息（可选撤销它产生的影响）

聊天页里**每条消息（你的 / 她的）右边都有一个 ✕**（桌面端悬浮出现，手机端常驻半透明）。点它会弹窗，里面有一个勾选项：

- **不勾**：只删除这条消息本身，记忆、关系数值、性格全都保留。
- **勾上（默认）**：连这条消息产生的影响一起撤销——
  - 这一轮抽取的记忆（含向量）
  - 性格信号 + 由它触发的性格 ±1 调整（会把维度值退回去）
  - 依恋信号 + 由它触发的依恋轴偏移
  - 情感银行的收支流水，并把余额调回去
  - 亲密度 / 信任 / 未解决张力 / 修复信用 / 心情 / 阶段
  - 这一轮的关系日志、冲突记录（这一轮新建且未修复的会删掉；这一轮修复掉的会重新标记为"未修复"）
  - 主动消息记录

**关系数值的还原策略**：如果删的是**最近一轮**，精确还原成"聊这句之前"的值；如果删的是**较早的某轮**，则只扣掉那一轮实际产生的增量，保留之后积累的成长（不会把你后续聊出来的关系一起抹掉）。

底层实现：每轮分析都会把"实际生效的增量 + 前的快照 + 日志 id 区间"写进 `turn_effects` 表，删除时按这张表精确回滚。同轮的另一条消息（比如她的回复）不会被连带删除。

### 5. 场景识别：线上聊天 / 线下相处

聊天页右上角有一个 **自动 / 线上 / 线下** 三段开关，安静地待在那儿，不打扰你：

- **自动**（默认）：智能识别。规则先判（零延迟）+ 后台分析用上下文校正。
  - 线下线索：抱、搂、牵、蹭、靠、递、喂、怀里、耳边、面对面、走近、坐旁边……
  - 线上线索：发消息、回我、微信、屏幕、打字、视频通话、朋友圈、截图……
- **线上 / 线下**：手动强制（手动优先，识别不会覆盖你的选择）。

场景会真实改变她的表达：
- **线下**：动作直接作用于你（牵手、靠着、把东西塞给你、抬头看你），禁止出现"回我消息/我在手机这头/晚点聊"这类异地话术，说话更像现场（更短、会被打断）。
- **线上**：动作围绕屏幕（盯对话框、打字、躺床上、裹被子），不许写身体接触，可以出现"等我一下我去倒水""发你张照片"，表情包更常用。
- 另外还会影响**主动消息**：你们正在一起（线下 + 12 小时内聊过）时，她不会给你发消息——那不合理。

### 6. 表情包（双向，她也看得懂）

- 输入框左边的 **😀 按钮**打开表情包面板，16 个可选（要抱抱 / 想你啦 / 别看我啦 / 我不管我委屈 / 哼！/ 困了 / 你可以的 / 摸摸你 / …… / 救命 / 哈哈哈哈 / 好喜欢你 / 不想说话 / 吃饭了没 / 你好久没找我了 / 太好了）。
- 你发的表情包在她眼里不是乱码：会转成「他发来一个表情包：😭「我不管我委屈」，意思是委屈、想被哄」这样的说明进入她的上下文，她会自然回应，而不是复述"你发了个表情包"。
- 她也会发：Prompt 里给了完整清单和使用规则（一次一个、不连续发、线上更常用），发出来就是表情包卡片。人味层保证表情包不会被当成"缺少动作"而硬塞括号描写。
- 表情包可以单独成条，也可以跟在台词后面；删除消息时和普通消息一样处理（可选连带撤销影响）。

### 7. 模型库 + 自动备用链（换模型不中断聊天）

「设置 → 模型档案」里保存了**你用过的所有模型**，随时一键切换，**立即生效**（配置存在数据库里，每次请求都重新读取，不用重启）：

- 每个档案存：接口地址 / Key / 聊天模型 / 分析模型 / 向量接口（可单独配置）。
- 一键 **测试** 每个档案的连通性与延迟；一键 **设为当前**；可 **编辑 / 删除 / 调整备用顺序**。
- **自动备用链**：当前模型报错、限流、超时（首字 12 秒无响应）时，自动按顺序切换到下一个模型，聊天不会中断。失败的模型进冷却（45 秒起，最长 10 分钟）后自动恢复。界面只会在设置页显示"实际服务的模型"。
- 首次启动自动收录档案：如果 `.env.local` 里已经配好接口，第一个档案就是「**当前配置**」（**不会覆盖你的设置**）；否则预置 **智谱 GLM-4.7-Flash** 为默认，另有 **智谱 GLM-4.5-Air** 备用。
  > 实测提醒：`glm-4.7-flash` 这个免费模型近期**严重过载**（大量 429、成功的一次耗时 100 秒+），所以它挂在最前面时会频繁触发自动降级——这是预期行为，聊天不受影响。想稳定，把「当前配置」（本地 vLLM）或「GLM-4.5-Air」设为当前即可。
- **后台分析可以换快模型**：`LLM_ANALYSIS_MODEL`（或每个档案里的「分析模型」）现在是真实生效的——记忆抽取、关系分析、每日摘要都会走分析模型，聊天模型不受影响。
- **向量接口与聊天模型分离**：换聊天模型时记忆向量仍走原来的向量模型，保证历史记忆的向量空间一致（否则老记忆会检索不准）。换向量模型后可以在设置页点「重算全部记忆向量」——现在会识别旧向量属于哪个模型并整体重算，不再只补缺失的。

### 8. 她的世界（世界模拟与生活系统）

她不是"只在聊天时存在"的机器人。新增「她的世界」页（导航第二个）：

- **健康**：精力 / 睡眠 / 饥饿 / 生病 / 生理周期 / 运动，随时间与作息自然漂移；生病由压力、淋雨等触发，持续 1-5 天，**被你关心会加速恢复**。

- **规则兜底识别**：她话里明确说"我去睡了 / 去洗澡 / 去吃饭 / 去运动 / 打游戏 / 做家务 / 护肤"等会被规则直接认出并登记，不依赖后台分析模型；你催她"去睡 / 去吃饭"她答应了也会登记。
- **状态手动调整**：世界页有「手动调整」，可直接设定她此刻的身体 / 心理数值，设定后立刻生效。

## 七、环境变量

`.env.local`（照着 `.env.example` 填一份，可随时改）：

```ini
LLM_BASE_URL=http://localhost:8000/v1     # OpenAI 兼容接口
LLM_API_KEY=你的APIKEY
LLM_MODEL=qwen3.8-27b                  # 聊天模型（角色扮演质量优先）
LLM_ANALYSIS_MODEL=glm-4.5-air   # 后台分析模型（快，建议保持 flash 类）
```

## 八、部署 / 换机器

### 本地开发（默认，`启动.cmd` 用的就是这个）

```bash
npm install
npm run dev          # http://localhost:3000
```

### 生产模式（更快、更省内存）

```bash
npm run build
npm start            # http://localhost:3000
```

### 部署到服务器 / 云主机

1. 把整个文件夹（**不含** `node_modules`、`.next`、`data`）拷过去。
2. `npm install && npm run build && npm start`。
3. 用 `pm2`、`systemd` 或 `nssm` 常驻；手机访问就在同一 Wi-Fi 下用 `http://电脑IP:3000`。
4. 定时任务（主动消息）是**进程内定时器**，只要服务在跑就会工作，不需要额外配置 Cron。

> 注意：不要用 Vercel 之类的 Serverless 部署。她依赖本地 SQLite 文件与常驻定时器，Serverless 上数据不持久、主动消息也不会触发。

## 九、常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| 双击 `启动.cmd` 一闪而过 | 没装 Node.js，或版本太低（需要 22.13 或更高），或安装后没重启电脑。装好 Node 22.13+ 再试 |
| 聊天没反应 / 提示发送失败 | 模型接口不通。打开「设置」页 → 点「连接自检」，看聊天模型一行是否 ✅ |
| 提示"本轮记忆抽取失败" | 后台分析模型返回异常，不影响聊天，她仍会正常回复。可在设置里把"深度思考"打开再试 |
| 她说话像客服 / 老问重复问题 | 记忆还没积累够（前几轮本来就会更客气）；也可以在「关系」页把阶段调高体验不同语气 |
| 想快点看到阶段跃迁 | 「设置」→ 阶段跃迁等待天数改成 0，亲密度到顶后她很快会找机会和你确认关系 |
| 想换模型（DeepSeek / 通义 / OpenAI） | 「设置」页改 Base URL + 模型名 + Key（都要是 OpenAI 兼容协议） |
| 想清空重来 | 「设置」→ 清空全部数据（保留设置）/ 恢复出厂状态；或直接删 `data` 文件夹 |
| 端口 3000 被占用 | 改 `package.json` 里的 `-p 3000` 为别的端口，例如 `-p 3100` |
